# Hyperlocal Role SOP Cards (Canva Brief)

## Goal
Create role-based SOP cards for consistent execution and faster onboarding.

## Output
A 9-card deck (1080 x 1080 each) with one role-action per card.

## Roles
- Vendor
- Delivery Partner
- Admin Support

## Card Set
1. Vendor: New order acceptance SLA
2. Vendor: Out-of-stock handling workflow
3. Vendor: Cancellation policy checklist
4. Partner: Accept/reject job rules
5. Partner: Delivery status update sequence
6. Partner: Failed delivery protocol
7. Admin: Refund review SOP
8. Admin: Complaint resolution SOP
9. Admin: Approval and audit logging SOP

## Card Structure
- Title
- Trigger condition
- 5-step action flow
- Escalation condition
- SLA target

## Style
- Bold headings, icon-led steps
- Consistent role color coding
- Print-friendly and mobile-friendly

## Usage
- Vendor/partner onboarding kits
- Internal training and QA audits
