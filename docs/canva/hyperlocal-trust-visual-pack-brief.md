# Hyperlocal Trust Visual Pack (Canva Brief)

## Goal
Create customer-facing trust visuals for checkout and post-order communication.

## Formats
- 1200 x 628 (web banners)
- 1080 x 1080 (social/help center)
- 1080 x 1920 (story format)

## Visual Set
1. Delivery Promise Banner
- `Live tracking, verified partners, safe handling`

2. Refund Policy Explainer
- Timeline graphic: request -> review -> resolution

3. Prescription Safety Flow
- Upload -> Verification -> Dispatch

4. Complaint Support Card
- Raise issue -> Ticket -> Resolution

5. Scheduled Delivery Clarity Card
- Slot confirmation and SLA behavior

## Copy Principles
- Plain language
- No legal jargon
- Clear turn-around times
- Action-first CTAs

## Placement
- Checkout panel
- Order timeline
- Help center module
- WhatsApp update templates
