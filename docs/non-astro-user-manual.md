# Malabar Bazaar Super App User Manual

## Overview

This manual explains the user-facing modules in the Super App, excluding the Astrology module.

The app is organized as a multi-module platform. Depending on your account type and enabled features, you may see different modules in the dashboard and navigation menus.

Typical entry points include:

- **Launch page** for sign-in or registration
- **Dashboard** for enabled modules and quick access
- **Admin dashboard** for platform management
- **Module pages** for each business area such as ecommerce, finance, healthcare, and more
- **Profile** for user account details
- **Support** for help and assistance

## Who can use the app

### Regular users
Can typically:
- Sign in and manage their profile
- Open enabled modules from the dashboard
- Use shopping, booking, communication, learning, and lifestyle tools
- Save preferences and view personal history where supported

### Admin users
Can typically:
- Access the admin dashboard
- Review registrations and applications
- Manage module availability
- Review subscription and operational data
- Monitor platform-level activity

## Getting started

1. Open the app.
2. Choose a registration or login path from the launch screen.
3. Complete sign-in or sign-up.
4. Open the dashboard.
5. Select a module from the dashboard, route, or quick links.

## Global navigation

The app uses shared navigation patterns across modules:

- **Dashboard**: primary home screen for enabled modules
- **Top header**: branding, language, account actions, and search where supported
- **Bottom navigation**: available in some mobile-style modules
- **Profile**: personal account and settings
- **Support**: help and contact information
- **Admin dashboard**: management tools for privileged users

## Troubleshooting

### I cannot open a module
Possible causes:
- You are not signed in
- The module is disabled
- Your account does not have permission
- The route has been redirected to a newer path

### A page redirects me back to the dashboard
This usually means:
- The module is not enabled for your account
- You are trying to open a restricted page
- You are missing required login or admin access

### Data is missing
Check that:
- The backend server is running
- Your session is active
- The module is enabled
- The page has finished loading

### A feature does not save
Try:
- Reloading the page
- Repeating the action after signing in again
- Checking whether the module is admin-only or backend-dependent

## Best practices
