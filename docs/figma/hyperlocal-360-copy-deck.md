# Hyperlocal 360 UX Copy Deck

## Voice
- Clear
- Action-focused
- Non-technical
- Reassuring in failure states

## Key Messages
- Scheduled: `Pick a delivery window to confirm slot availability.`
- Idempotent replay: `Your previous order request was already processed. Showing latest confirmed result.`
- Payout guardrail: `Requested payout is above available balance.`
- Inventory: `Some items changed in stock. Review cart and retry.`
- Audit visibility: `This action is recorded for compliance.`

## Empty States
- User: `No orders yet. Place your first hyperlocal order.`
- Vendor: `No vendor orders yet.`
- Partner: `No delivery jobs available now.`
- Admin: `No pending requests right now.`
- 360: `No data yet. Refresh after operations begin.`

## Error CTA Patterns
- Primary: `Retry`
- Secondary: `View details`
- Escalation: `Contact support`
